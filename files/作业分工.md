# 作业二：GUI 测试任务规划与分工

## 1. 选定网站

**题目：基于 Selenium 与大模型辅助的 SauceDemo 电商网站 GUI 自动化测试**

被测网站：

```text
https://www.saucedemo.com/
```

测试账号：

```text
username: standard_user
password: secret_sauce
```

选择 SauceDemo 的原因：

- 是典型电商 Web 应用，符合 GUI 测试作业要求。
- 有登录、商品列表、商品详情、购物车、结算、订单完成等完整流程。
- 有多页面跳转，满足“两级以上页面”要求。
- 覆盖按钮、输入框、表单、下拉框、链接、侧边栏/导航菜单等元素。
- 无真实支付、验证码和复杂反爬，适合 Selenium 自动化测试。
- 可用浏览器移动端视口模拟移动端 Web 测试。

## 2. 总体需要完成的工作

本次作业需要完成以下内容：

1. 编写《测试计划》。
2. 使用 Selenium 编写并运行 GUI 自动化测试代码。
3. 使用大模型/agent 辅助生成测试计划、测试脚本和测试报告。
4. 保存大模型交互过程，包括提示词、反馈和截图。
5. 编写《测试报告》。
6. 在报告中写明小组成员贡献与比例。

最终提交材料：

```text
《测试计划》
测试代码
《测试报告》
《基于大模型的软件测试使用记录》
```

## 3. 测试范围

测试流程围绕 SauceDemo 的核心购物流程展开：

```text
登录页 → 商品列表页 → 商品详情页 → 购物车页 → 结算页 → 订单完成页
```

计划测试的功能/事务：

| 编号 | 功能/事务 | 说明 |
|---|---|---|
| TC01 | 登录并进入商品浏览流程 | 输入账号密码，验证进入商品列表页 |
| TC02 | 商品排序 | 使用下拉框对商品进行排序 |
| TC03 | 查看商品详情 | 点击商品链接，进入详情页 |
| TC04 | 添加商品到购物车 | 点击 Add to cart，检查购物车数量 |
| TC05 | 购物车页面检查 | 进入购物车，检查商品信息 |
| TC06 | 结算与订单完成 | 填写结算表单并完成订单 |
| TC07 | 移动端视口测试 | 模拟手机浏览器尺寸，测试核心流程 |

说明：登录不单独作为核心功能凑数，只作为后续购物流程的前置步骤。

## 5. 技术方案

测试框架：

```text
Python + Selenium + pytest
```

建议依赖：

```text
selenium
pytest
webdriver-manager
```

移动端测试方式：

- 不使用真实手机和 Appium。
- 使用 Selenium 设置浏览器窗口尺寸或 Chrome mobile emulation。
- 验证移动端视口下页面布局和核心流程是否正常。
