\section{测试概述}

本次 GUI 自动化测试以 SauceDemo 电商网站为被测对象，围绕电商网站中常见的商品浏览、排序、详情查看、购物车、结算和移动端补充验证等事务开展测试。SauceDemo 页面结构清晰，业务流程完整，且包含按钮、输入框、表单、下拉框、链接、侧边栏、购物车标记等多种 Web 元素，适合作为课程作业中的 GUI 自动化测试对象。

测试采用 Selenium WebDriver 模拟用户在浏览器中的真实操作，并使用 pytest 组织测试用例和执行结果。报告围绕测试计划中确定的功能事务展开，记录测试设计、Web 元素覆盖、用例执行结果和测试结论。

（如果移动端 Web UI 测试执行成功，需要在本节补充移动端测试对象说明，例如 Android Chrome 或移动端视口下的 SauceDemo Web 页面。）

\section{测试范围}

本次测试覆盖 SauceDemo 的核心购物路径：

\begin{lstlisting}
登录页 -> 商品列表页 -> 商品详情页 -> 购物车页 -> 结算页 -> 订单完成页
\end{lstlisting}

整体测试事务包括登录后进入商品浏览流程、商品排序、查看商品详情、添加商品到购物车、购物车页面检查、结算与订单完成、侧边栏导航菜单和移动端 Web UI 轻量抽测。其中，桌面端 Web 测试用于验证主要业务流程，移动端 Web UI 测试作为补充抽测，用于检查移动端浏览器环境下的关键触控和页面滚动操作。

（如果移动端 Web UI 测试执行成功，需要在本节补充移动端测试范围，例如登录页显示、商品列表滑动、触控点击 Add to cart 和购物车 badge 状态变化；如果采用回退方案，需要说明该范围属于移动端视口模拟验证。）

测试用例按照“操作步骤可复现、检查点明确、结果可断言”的原则编写。自动化测试使用 Selenium 模拟真实浏览器操作，并通过 pytest 对页面跳转、元素显示状态、业务数据和交互结果进行断言。测试失败时会自动在 artifacts/screenshots 目录下保存截图，便于定位问题。

\section{问题与结论}

TC01 和 TC02 均执行通过，验证了标准账号进入商品列表页、商品列表页关键元素显示以及商品排序下拉框的四种排序规则。测试结果表明，SauceDemo 的商品浏览入口和商品排序功能表现正常，未发现影响登录后商品浏览和排序操作的功能异常。
